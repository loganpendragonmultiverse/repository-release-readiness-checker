# Testing

Run `python -m pip install -e . pytest build`, `python -m pytest` and
`python -m build`, retaining the entire native CI and CodeQL matrix.
Install the wheel and source distribution in fresh environments outside the
checkout and repeat the complete suite and three CLI report formats.

Regressions prove no Git/subprocess invocation, no symlink source reads,
bounded/non-text inspection evidence, conservative baseline resolution, inert
empty Markdown links, value-free missing-link diagnostics, .env ignore comment/
negation behavior, and preservation of existing or competing output files.

Large binary fixtures use explicit short pytest IDs so PYTEST_CURRENT_TEST stays within Windows environment limits; retain the original payloads and assertions.
